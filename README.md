# OMEN Gaming Hub Notifier

Discord notifier for free giveaways available through OMEN Gaming Hub.

## Features

- Checks the OMEN Gaming Hub giveaways API
- Detects new in-app giveaways
- Filters for `GameCodeHPID` giveaways
- Prevents duplicate Discord notifications
- Sends giveaway information through a Discord webhook

## Requirements

- Python 3
- `requests`
- Discord webhook

## Running locally

Install dependencies:

```bash
pip install -r requirements.txt
